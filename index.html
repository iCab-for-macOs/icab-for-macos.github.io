iCab for Mac

iCab is an alternative web browser built for precision and control. Supporting HTML4, image and cookie filtering, bookmarks, Java and JavaScript, search modes, web archives, download management, and features unmatched by others. Version 6.3.7 brings refined URL handling and modern macOS integration.

Ad and Banner Filtering

Block advertising banners effortlessly. Maintain a clean, distraction-free browsing experience with intelligent filtering that adapts to your needs.

Advanced Download Management

Handle downloads with a dedicated manager. Choose custom save locations via context menu, track progress, and resume interrupted transfers seamlessly.

URL Mapping

Transform URLs before they load. Redirect YouTube to embedded players, skip Shorts, restore classic Reddit, strip tracking parameters—or craft your own rules for ultimate control.

Kiosk Mode and Portability

Lock into kiosk mode for focused sessions. Create portable web archives that work anywhere, without dependencies.

Link and Source Management

Organize links efficiently. Inspect and manage source code directly. Error protocols with visual feedback keep you informed at every step.

How It Works

Step 1: Install and Launch

Download, drag to Applications, and open iCab. Your activated version is ready—no purchases needed.

Step 2: Customize Filters

Enable ad blocking, cookie filtering, and image controls in preferences. Tailor to your workflow instantly.

Step 3: Map URLs

Access Tools > URL Mapping. Apply predefined rules or add custom ones for redirects and parameter removal.

Step 4: Browse and Manage

Use download manager for files, link manager for organization, and kiosk mode for immersion. Enjoy seamless macOS Liquid Glass visuals.
